# Datenschutzerklärung

Diese Anwendung wird ausschließlich vom Betreiber für sein eigenes Google-Konto genutzt.

- Google Drive: Zugriff nur auf Dateien, die die Anwendung selbst angelegt hat (Datensicherungen).
- Google Kalender: nur lesender Zugriff zur Anzeige eigener Termine im privaten Netz.
- Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.
- Zugangsdaten werden nur lokal auf dem eigenen Server gespeichert.

Die Freigabe kann jederzeit unter https://myaccount.google.com/permissions widerrufen werden.
